# 01 Login & Register System

📌 Project Overview
The Login & Register System is a Java Full Stack web application developed using JSP, Servlets, JDBC, MySQL, HTML, and CSS. The project allows users to create an account, log in securely, maintain a session, and access a personalized welcome page.

🚀 Features
-User Registration
-User Login Authentication
-Session Management
-Welcome Dashboard
-Logout Functionality
-MySQL Database Integration
-JDBC Connectivity
-Responsive User Interface
-Error Handling for Invalid Login
